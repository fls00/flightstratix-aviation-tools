## The problem

Most flight operations still run on spreadsheets, WhatsApp threads, and a dozen disconnected tools. Quotes live in one place, the trip in another, crew hours somewhere else, and invoices go out days late. Nothing talks to each other, and the person holding it all together is a human memory that doesn't scale.

FlightStratix pulls the whole operation into one place — from the first quote to the final invoice — so nothing slips through the cracks.

---

## What it does

Every part of a trip, connected. Below is what each tool solves.

### Move the trip forward

- **Trips** — The single source of truth for every movement. Every leg, service, and status in one view, so no one has to chase updates. → [app.flightstratix.com](https://app.flightstratix.com)
- **Bookings** — Turn an inquiry into a confirmed trip without re-typing anything. The request carries through instead of starting from scratch.
- **Aircraft Timeline** — See what every tail is doing at a glance. Spot conflicts and gaps before they become AOG surprises.
- **Permits** — Track overflight and landing permits per leg so nothing gets flown without clearance.

<!-- <p><img src="./assets/screenshot-trips.png" alt="Trips view" width="100%"></p> -->

### Handle the services

- **Ground Handling** — Coordinate handlers per stop and keep every request in one thread instead of scattered emails.
- **Fuel** — Manage fuel arrangements per leg without switching tools.
- **Catering** — Log passenger and crew catering against the trip so nothing gets missed on the ramp.
- **Concierge** — Track transport, hotels, and extras alongside the trip they belong to.

### Keep crew legal and rested

- **Crew** — One profile per crew member: documents, currency, and details in one place.
- **Crew Rota** — Assign and see who's flying what, without a separate scheduling spreadsheet.

### Know your fleet

- **Aircraft** — Every tail's details, docs, and availability in one record the whole team can trust.

### Run the relationships

- **Clients** — Client records tied to their trips and history, so context is never lost.
- **Passengers** — Passenger details ready to reuse, not re-collected every trip.
- **Vendors** — One directory of handlers, fuelers, and suppliers your team actually uses.

### Get paid

- **Quotation** — Build a quote fast and turn it straight into a trip when it's won.
- **Invoicing** — Invoice off the trip that actually happened, so billing matches reality.
- **Fuel Management** — Keep fuel costs and reconciliation tied to the operation.
- **Documents** — Every file — permits, sheets, confirmations — attached where it belongs.
